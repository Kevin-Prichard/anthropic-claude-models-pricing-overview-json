Generate four Python 3 functions which each extract one of the four data tables from the HTML document "data/Models overview - Anthropic.html" in this repo.  Use lxml and XPath to select the tables, extract their row and column labels and table cells, and convert them into dicts.

1. The table labeled 'Model names' will be converted to a dict with the following format, where the changing values are stubbed out using "<...>" placeholder syntax:

ANTHROPIC_MODEL_MAP = {
    "<model name>": {
        "anthropic": "<claude model tag>",
        "aws_bedrock": "<aws bedrock model tag>",
        "gcp_vertex_ai": "<google gcp model tag>",
    },
    {...}
}

For example:

ANTHROPIC_MODEL_TAGS = {
    "Claude 4 Sonnet": {
        "anthropic": "claude-sonnet-4-20250514",
        "aws_bedrock": "anthropic.claude-",
        "gcp_vertex_ai": "claude-sonnet-4@20250514",
    },
    "Claude 4 Sonnet": {
        "anthropic": "claude-sonnet-4-20250514",
        "aws_bedrock": "anthropic.claude-",
        "gcp_vertex_ai": "claude-sonnet-4@20250514",
    },
    "Claude 3.7 Sonnet": {
        "anthropic": "claude-3-7-sonnet-20250219",
        "aws_bedrock": "anthropic.claude-3-7-sonnet-20250219-v1:0",
        "gcp_vertex_ai": "claude-3-7-sonnet@20250219",
    },
    ...
}

2. The table labled 'Model aliases' will be converted to a dict with the following format, following the convention described in #1:

ANTHROPIC_MODEL_TAG_ALIASES = {
    "Claude Opus 4": {
        "alias": "aliasclaude-opus-4-0",
        "model_id": "claude-opus-4-20250514"
    },
    ...
}

ANTHROPIC_MODEL_TAG_ALIASES = {
    "<model name>": {
        "alias": "<model alias>",
        "model_id": "<model id/tag>"
    },
    ...
}

ANTHROPIC_MODEL_TAG_ALIASES = {
    "Claude Opus 4": {
        "alias": "aliasclaude-opus-4-0",
        "model_id": "claude-opus-4-20250514"
    },
    "Claude Sonnet 4": {
        "alias": "claude-sonnet-4-0",
        "model_id": "claude-sonnet-4-20250514"
    },
    ...
}

3. The table 'Model comparison table' will be converted to a dict with the following format, as above:

ANTHROPIC_MODEL_FACTS = {
    "<model name>": {
        "Description": "<description>",
        "Strengths": "<strengths>",
        "Multilingual": <boolean>,
        "Vision": <boolean>,
        "Extended thinking": <boolean>,
        "Priority Tier": <boolean>,
        "API model name": "<model id>",
        "Comparative latency": "<latency>",
        "Context window": <context window as integer>,
        "Max output": <max output as integer>,
        "Training data cut-off": <training data cut-off date as datetime,
    },
    ...
}

For example:
ANTHROPIC_MODEL_FACTS = {
    "Claude Opus 4	": {

    ...
}
