# Summary

Offering Anthropic model pricing information as machine-readable data for developers.

## Overview

This project scrapes and publishes, as JSON and CSV, the contents of https://docs.anthropic.com/en/docs/about-claude/models/overview

The goal is to make Anthropic model pricing data more available and accessible to AI developers.

The purpose of this project is to publish the metadata via web and git.

## Publishing
The scraper of this project will be run from a cloud function service, such as AWS Lambda or Google Cloud Functions. It is assumed that the function will be triggered by a cron job or similar scheduling service.
